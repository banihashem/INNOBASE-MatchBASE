# Developer command catalog

Activity: **MB-UX-GOV-003 L01**. This catalog classifies the existing command surface; it does not rename commands or retire compatibility consumers. Run commands from `C:/INNOBASE/MatchBASE/03_Implementation/INNOBASE-MatchBASE`. Current startup uses Docker; the host lifecycle descriptions below are compatibility context and must not run alongside Docker. `pnpm run` and each workspace's `package.json` remain the exact executable index.

## Current development and Consultant runtime

| Command                                                                       | Purpose and effects                                                                              |
| ----------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| `pnpm run check:dev`                                                          | Formatting, lint, boundaries, protected history, secret scan, and workspace typechecks.          |
| `pnpm run test:unit`                                                          | Workspace unit/component tests.                                                                  |
| `pnpm run test:integration`                                                   | API/repository/integration regressions; use the intended local test environment.                 |
| `pnpm run build`                                                              | Builds workspace packages and application artifacts.                                             |
| `pnpm --filter '@matchbase/application...' build`                             | Builds Consultant worker and its workspace dependencies.                                         |
| `pnpm --filter @matchbase/web dev`                                            | Starts the current Next.js development UI.                                                       |
| `pnpm --filter @matchbase/application worker:consultant`                      | Polls and executes durable Consultant jobs. Queued Live jobs can make paid provider calls.       |
| `pnpm --filter @matchbase/data migrate`                                       | Applies registered schema migrations to `MATCHBASE_DATABASE_URL`; changes the selected database. |
| `node --test test/slice2/application/approved-request-lineage.test.mjs`       | Focused canonical-request lineage regression after application build.                            |
| `pnpm exec playwright test --config playwright.consultant-live-ui.config.mjs` | Controlled browser UI qualification; inspect the test setup and current server origin.           |

The root local runtime scripts manage only their own PID/instance records. `START ... -Restart` drains the Consultant worker before relaunch. Web/Both stop or restart requires an operator-confirmed idle web application: Next dev does not guarantee active HTTP/after-callback draining on Windows, and the scripts do not automatically check database idleness. They never stop a database, kill a process merely because it uses a port, or read a credential file. Their heartbeat reports process liveness; database job/event inspection establishes worker progress.
