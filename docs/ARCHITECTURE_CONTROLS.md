# Consultant execution, evidence memory and recovery controls

Activity: **MB-ARCH-IMPLEMENT-001 L01–L05**. The local product-state authority remains `C:/INNOBASE/MatchBASE/PROJECT_START_HERE.md`. This document describes the implemented contracts; it does not claim production identity, shared-corpus activation, measured cost savings or universal failure recovery.

## Durable execution

Research attempts are reserved transactionally against the current logical request, execution lease, immutable approval, deadline and remaining call allowance. Provider receipts update accounting even after cancellation. A missing receipt remains an uncertain external effect; neither a process restart nor a low estimated cost authorizes repeating it.

Complete stage artifacts retain their input, approval, model policy, schema and validator hashes. Eligible committed results can be reused by a reclaimed worker, while downstream validation still runs. Atomic publication checks prevent cancelled, superseded or expired work from replacing the current result. Recovery stays within the approved limits; a new quote is required when authority changes.

## Private evidence and renewal

Newly completed live rounds populate profile-scoped source versions, entity identities, observations and dependency records. Original publication/offer dates remain distinct from retrieval dates. Exact registration identifiers require jurisdiction and supporting source evidence; ambiguous company names remain unresolved. Exact/lexical retrieval is the current reference. No embedding or graph-summary service is activated by this change.

Quotes bind the selected evidence version and input budget. Rights, freshness, classification and ownership are checked again before paid work and publication. Expired observations are excluded from reuse; fresh discovery still searches beyond remembered suppliers. Historical reports retain their dates, while explicit rights withdrawal or source correction withholds affected output and exports without erasing the request history or cost record.

A renewal creates a linked new run with a new execution and classification assignment under the same authorized profile. The logical request groups the history and costs; it does not replace the four operational IDs. Compatible unchanged approvals are adopted by explicit hash reference. New cost approval is always required, and the five-round limit applies independently to the new run. Root generation checks reject duplicate or stale continuations.

The Consultant workflow exposes these controls through **Research history & saved evidence**. Opening history performs no model call. **Refresh this research** opens a linked request for a new estimate; it does not dispatch research.
