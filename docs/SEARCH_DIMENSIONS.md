# Search dimensions

Activity: MB-SEARCH-DIMENSIONS-002 L01.

## User journey

Section 2 contains optional research profiles and searchable grouped dimensions. Core evidence policies remain active. Users can add private custom dimensions to their category, choose the relevant investigation questions and save before approving the request or research plan. Explicit buyer requirements cannot be removed by a toggle. The profile is a research aid; it never replaces the run's primary classification or claims an official code mapping.

New requests infer provisional profiles from their text. The catalogue currently supplies core, ocean freight/forwarding, chemical supply and industrial pump packs. Other industries use core plus private custom definitions; adding a reviewed public pack uses the typed registry and its qualification tests. Catalogue edits require source review and a registry version change. Custom definitions remain account/profile/category scoped and append immutable revisions.

## Authority and persistence

The server assigns ownership. A selection save requires the current revision and serializes against prompt approval. Configuration and compiled plan are persisted in workflow metadata; approval freezes the plan. A changed plan changes the research request hash and cannot reuse a prior quote. Edits are rejected after research prompt approval, while jobs are active or once a research round exists. Existing approved historical sessions/results remain unchanged.

Migration 0028 adds the private revision catalogue. Each revision records account ownership plus user profile, research run, execution and immutable primary classification identifiers. Context assignments are separately named scoped records and cannot replace this four-ID lineage. The existing durable round commit persists the plan, source observations and assessments before result publication.

## Research and output

The compiled manifest guides the existing approved searches and extraction batches. It grants no additional calls, automatic rounds or spending. Private lookup uses selected question terms as research clues under the existing owner, rights and expiry gates. Arbitrary `search_dimensions.<id>` facts require literal source evidence and remain claims requiring semantic review; their labels cannot establish eligibility.

The conservative legacy adapter admits research-only contact, headquarters and explicitly dated supplier price observations. Prices require same-source amount, currency, unit and explicit publication date, within thirty days and any evidenced validity. Research-only observations retain unknown fit. Unsupported, contextual or other dynamic predicates remain unexecuted/unknown until a qualified semantic adapter can establish their exact scope. Typed AND/OR/NOT and lot evaluation exist, but this adapter does not manufacture scoped observations or complete capability sets. Old six-bucket scores and stored rankings are preserved.

Summary, dossier and English PDF use the same persisted assessments. Collected dimension-labelled claims are visible separately from admitted observations. The output parser independently recomputes the projection from the pinned plan and actual claims/sources, rejecting substituted lineage, evidence or eligibility.
