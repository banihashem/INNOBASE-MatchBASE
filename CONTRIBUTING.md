# Contributing

This is a private, evidence-gated repository.

1. Work on a short-lived branch from protected `main` after protection exists.
2. Keep changes within the authorized slice and update the machine-readable registers.
3. Run `pnpm test:ci` before commit.
4. Attach deterministic evidence: exact command, exit code, artifact path, and SHA-256.
5. Require independent review with zero critical, major, and minor defects.
6. Never weaken checks to obtain a pass.

No public contribution or external distribution is authorized.
